# Entities — u1-core-game

This entity model refines the ownership and shape fixed in `inception/domain-design/components.md` (Rooms, Games) for unit U1 in `inception/units-generation/unit-of-work.md`. It covers the requirements mapped to U1 in `inception/units-generation/unit-of-work-story-map.md` and `inception/requirements-analysis/requirements.md`. Notifications entities belong to U5 and are not defined here.

```yaml
entities:
  - name: Room
    description: A shareable room; the lifetime container for seats, games and the match score.
    owner: Rooms
    attributes:
      - { name: code, type: string, required: true, unique: true, constraints: "exactly 6 chars from A-Z and 0-9; generated by a cryptographic RNG; uppercase-normalised on input" }
      - { name: createdAt, type: timestamp, required: true }
      - { name: lastActivityAt, type: timestamp, required: true, constraints: "updated on create, join, move, claim, rematch, seat transfer" }
      - { name: winsA, type: integer, required: true, default: 0, min: 0 }
      - { name: winsB, type: integer, required: true, default: 0, min: 0 }
      - { name: draws, type: integer, required: true, default: 0, min: 0 }
      - { name: rematchRequestedBy, type: enum, required: false, allowed: [A, B], constraints: "null when no pending request" }
      - { name: rematchRequestedAt, type: timestamp, required: false }
    constraints:
      - "at most two Seats"
      - "the current game is the Game with the highest number for this room (no stored pointer)"
    relationships:
      - { to: Seat, cardinality: "1 to 0..2", direction: "Room has Seats" }
      - { to: Game, cardinality: "1 to 1..n", direction: "Room has Games" }

  - name: Seat
    description: One of the two player positions in a room, independent of colour.
    owner: Rooms
    attributes:
      - { name: seatId, type: identifier, required: true, unique: true }
      - { name: roomCode, type: reference, required: true, references: Room.code }
      - { name: slot, type: enum, required: true, allowed: [A, B], constraints: "A = creator, B = joiner; unique per room" }
      - { name: tokenHash, type: string, required: true, unique: true, constraints: "SHA-256 of a token with at least 128 bits of randomness; the plaintext is never stored" }
      - { name: continueTokenHash, type: string, required: false, unique: true, constraints: "SHA-256 of the continue token; null until requested" }
      - { name: lastSeenAt, type: timestamp, required: true, constraints: "set on join and on every socket heartbeat or action of this seat" }
    relationships:
      - { to: Room, cardinality: "n to 1", direction: "Seat belongs to Room" }

  - name: Game
    description: One game of chess played in a room.
    owner: Games
    attributes:
      - { name: gameId, type: identifier, required: true, unique: true }
      - { name: roomCode, type: reference, required: true, references: Room.code }
      - { name: number, type: integer, required: true, min: 1, constraints: "unique per room; 1 for the first game, +1 per rematch" }
      - { name: whiteSlot, type: enum, required: true, allowed: [A, B], constraints: "A for game 1, then alternates" }
      - { name: fen, type: string, required: true, constraints: "current position" }
      - { name: version, type: integer, required: true, default: 0, min: 0, constraints: "+1 on every accepted change (move, claim, end)" }
      - { name: status, type: enum, required: true, allowed: [waiting, playing, finished], default: waiting }
      - { name: endReason, type: enum, required: false, allowed: [checkmate, stalemate, insufficient_material, fivefold_repetition, seventyfive_moves, threefold_claimed, fifty_moves_claimed, abandoned] }
      - { name: result, type: enum, required: false, allowed: ["1-0", "0-1", "1/2-1/2"] }
      - { name: startedAt, type: timestamp, required: false }
      - { name: endedAt, type: timestamp, required: false }
    relationships:
      - { to: Room, cardinality: "n to 1", direction: "Game belongs to Room" }
      - { to: Move, cardinality: "1 to 0..n", direction: "Game has Moves" }

  - name: Move
    description: One half-move in a game.
    owner: Games
    attributes:
      - { name: gameId, type: reference, required: true, references: Game.gameId }
      - { name: ply, type: integer, required: true, min: 1, constraints: "unique per game; 1-based" }
      - { name: uci, type: string, required: true }
      - { name: san, type: string, required: true }
      - { name: playedAt, type: timestamp, required: true }
    relationships:
      - { to: Game, cardinality: "n to 1", direction: "Move belongs to Game" }

  - name: SchemaVersion
    description: The database schema marker that decides whether the store is reused or replaced at startup (ADR-006).
    owner: HttpApi
    attributes:
      - { name: version, type: integer, required: true, constraints: "2 for P1; a missing marker or a lower value means a fresh start" }
```

## Summary

- **Room** holds the code, the per-seat score and any pending rematch request. It no longer stores tokens or a game pointer; the current game is always the highest-numbered Game in the room.
- **Seat** is the player's identity in a room, keyed by slot A or B rather than by colour. That way the score follows the player when colours swap (FR4.5). Only token hashes are stored (NFR2).
- **Game** and **Move** are one game and its half-moves. The version number guards against duplicate or out-of-order moves (FR3.10). The end reason drives the end-of-game overlay text (FR4.1, FR4.2).
- **SchemaVersion** decides the fresh start (FR11.1).
