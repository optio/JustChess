### Summary

The design covers the U3 requirements, texts and layout constraints, and the API, socket and token handling fit U1. Three Major gaps would make a developer guess or build the wrong thing: the join response holds no snapshot, the stale-token rule relies on a 403 the server never sends, and the screen state machine is incomplete and contradicts the status-line order. Fix those three and the Minor items, which are mostly small contract clarifications, and the design is READY.
